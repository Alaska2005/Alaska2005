## Projects

**[OrgDoc AI](https://github.com/Alaska2005/OrgDocAI)** — [Live](https://org-doc-ai.vercel.app)

A full-stack platform for organizations to manage events, documents, and media — with an AI chatbot and semantic search built on top using RAG (LangChain + ChromaDB). Built with React, Node.js, PostgreSQL, and Cloudinary.

---

**[Portable Solar Radio Telescope](https://github.com/Alaska2005/Portable-Solar-Radio-Telescope)**

A low-cost, portable radio telescope for observing solar activity. Uses RTL-SDR hardware with a Python signal processing pipeline to detect solar radio bursts.

---

**[Hydrogen Line Analysis Tool](https://github.com/Alaska2005/Hline-analysis-tool)**

A GUI-based tool for capturing and analyzing the 21 cm hydrogen line signal via RTL-SDR — used in amateur radio astronomy setups.
